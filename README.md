# PennylessTrack

El objetivo es una aplicación que gestiona los gastos de los clientes.

**Tecnologías**: React y Laravel.

#

**REACT**

npm create vite@latest mi-proyecto -- --template react

cd mi-proyecto

npm install

npm run dev

**LARAVEL**

composer create-project laravel/laravel nombre-del-proyecto

cd nombre-del-proyecto

php artisan serve

#

**TESTS REACT**

npm test

**TESTS LARAVEL**

php artisan test
